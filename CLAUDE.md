# LuniBots: working agreement

## UI work
Before writing or changing any UI, read and apply all of these. They are always in context:

@skills/design-principles.md
@skills/typography.md
@skills/layout.md
@skills/anti-patterns.md

Style references live in `references/references.md`. For every design decision, name the rule ID (D/T/L/A) or reference it came from; if neither applies, don't make the choice.
Constraints: custom CSS with tokens, 1px borders, radii 0–2px, no shadows, no gradients unless a reference justifies one, no component libraries that impose a look.
