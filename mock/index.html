Modmail

v1.0.0 · beta

Members DM the bot. Each conversation becomes a public thread in one tickets channel, where staff reply (optionally anonymously), claim, and close it. Closed tickets are saved as transcript files in a private channel and can be searched later.

Commands

/reply <message> [anonymous]Reply to the user from inside a ticket
/claim · /unclaim [reason]Take or release a ticket
/close [reason]Close the ticket and generate a transcript
/logs user · /logs searchTicket history for a user; search closed transcripts
/snippet add|remove|list|useCanned responses

Also: /closeall, /config, /help.

Safety & cost

What is this?
A catalogue of Discord bots you host yourself. You get the code and run it.
Is it free?
Yes. No accounts, no paywall. DiscMeet calls OpenAI, which bills you directly.
Is it safe?
Downloads link to GitHub Releases, never to this site. When a release ships a checksum, it is shown next to the file. The source is readable before you run it.
Telemetry
None on this site. Neither bot reports anywhere except Discord; DiscMeet also sends audio and text to OpenAI.
